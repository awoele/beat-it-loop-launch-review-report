Executive summary

摘要

供给跑通，消费未跑深。 Beat It Loop 已进入 Power 头部，生成与发布链路成立；当前增长上限主要来自公开发布规模、单作品播放强度，以及玩法表达是否足够明确。

最大的增长空间，不等于异常故障

887 个 project 停在有效公开之前，是全链路最大的绝对损耗；但 44.53% 的发布率仍略高于 Power 大盘，因此应描述为“最大可优化空间”，而不是“发布链路失效”。

过程诊断

失败不是主因

未完成率仅 4.16%，明确失败原因 task 占 2.34%（40 个）。若目标是扩大供给，应优先处理生成后的公开意愿与发布摩擦。

只能写“联用组表现更高”

联用不是随机分配：更成熟的创作者、更明确的目标或头部作品都可能同时影响联用与消费。该对照不能直接证明联用造成提升。

数据质量与因果边界
  • 当前报告主窗口为 1,708 task / 1,599 project；本地 11 张 FAST 明细是早期 924 / 911 窗口，只作历史补证，不与主指标混算。

  • 报告优先展示样本数；下一版建议补齐中位数、P75/P90 与去极值结果。
